# Contributing

Thank you for helping Noemosyne preserve inspectable reasoning.

1. Open an issue for semantic schema or invariant changes and include an ADR proposal.
2. Create focused commits and add tests at the relevant unit, property, integration, contract, or end-to-end layer.
3. Run `make check` and document deliberate fixture or OpenAPI changes.
4. Add `Signed-off-by: Name <email>` to each commit to certify the [Developer Certificate of Origin 1.1](https://developercertificate.org/).

Software contributions are Apache-2.0. Original example annotations and documentation contributions are CC BY 4.0 unless a file states otherwise. Do not submit copyrighted source content without a redistributable license and explicit license basis.
