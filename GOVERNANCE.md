# Governance

Noemosyne currently uses a maintainer-led model. Maintainers merge changes, cut releases, enforce provenance and review separation, and steward the normative epistemic vocabulary. Material invariant, governance, licensing, or compatibility changes require a public ADR and maintainer approval. Routine fixes use normal review.

Maintainers must disclose conflicts and abstain when they cannot review independently. Accepted governance decisions are recorded in the repository. As the contributor base grows, this document will name maintainers and define succession and voting thresholds.
